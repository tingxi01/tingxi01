### ♡ Featured Project

#### [Enterprise AI Assistant](https://github.com/tingxi01/enterprise-ai-assistant)

A full-stack AI document assistant built using
retrieval-augmented generation (RAG).

The application allows users to upload PDF documents,
ask questions in natural language, and receive
context-aware answers supported by source citations.

**Highlights**
- PDF document processing and vector embeddings
- Hybrid semantic and keyword retrieval
- Local LLM integration using Ollama
- Conversation-aware follow-up questions
- React frontend and FastAPI backend
- PostgreSQL with pgvector
- Docker Compose and automated testing

[View Repository](https://github.com/tingxi01/enterprise-ai-assistant)
